# 四图视觉和食谱标准

默认3:4竖幅，全屏食物/厨房照片；手机随手拍的真实光线与不规则切面，不做光滑塑料感、完美圆润块状食物。粗白字黑描边，字体活泼，描述普通准确。顶部约10%、侧边约6%内不放关键文字，文字不挡食物辨识。不得写“0基础”“保证成功”。

1. 成品封面：菜名+一句准确口感或做法描述，成品占主要画面；默认没有人。不要重复过程图文字。
2. 备菜：每个食材对应局部照片，文字直接写在对应区域，份量与recipe一致。葱“一把”不能摆满桌；虾皮一小把应为少量浅色半透明细小整虾，不是肉厚金黄虾米。盐、油、生抽等实际使用的调味也需列出；不用纯文字清单挤在角落。
3. 步骤：通常4至6格，必要时最多8格且必须保证手机可读。每格动作与照片一致，按操作先后；写火候、时间范围、成熟/收汁判断。调料汁画面不能配煎豆腐步骤。炖骨头等耗时工序不能省略时间；原料厚度、锅具差异需说明。
4. 食用补充：不露脸的真实家常吃饭场景，筷子或勺子夹起食物；如出现身体，持筷手与同一个成年人的身体连接，不漂浮多手。用户要求时穿普通夏装；不得凭空添加人物到第1张。少量字，不重复详细教程。

## 一致性验收
- 统一菜名、餐具主风格、食材种类、切块形状、颜色和份量；方豆腐不可变圆柱豆腐。
- 米粒大小和黏连自然；牛腩纤维与不规则切面明显；茼蒿叶型和茎叶比例真实。
- 调味数量可执行：同种调料用于腌制和料汁时写清分配；用盐与否以当前recipe为准，不能为凑模板随意加。
- 少油方法应体现在备菜与过程，不只是封面写少油；青椒酿虾滑可整根灌馅再切，必须与当前参考教程一致。
- 真实参考必须有实际查看证据；保留来源，不去水印冒充原创照片。最终标注为参考照片生成/改造的AI图，不声称亲自拍摄。
- 四图文字逐字检查、无乱码、不被裁切；明确图2食材齐全、图3步骤完整，图4不是封面重复。

## 返修规则
保留原文件；版本追加v2等，metadata指向已验收版本。只改用户指定项，不擅自换菜、换配方或重做其他图片。指定原图需保留内容但模型编辑可能变化，需检查而不是保证像素级一致。
