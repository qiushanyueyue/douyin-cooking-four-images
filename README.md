# 抖音家常菜四图：ChatGPT GPT 生图 Skill

中文生图规范：**优先在 ChatGPT 使用 GPT 生图**，以用户提供的真实视频/照片为依据，制作四张独立3:4食谱图；兼顾单图返修、提示词交付和作品数据复盘。

## 四图结构
1. **封面**：菜名醒目，真实家常份量，默认无人物。
2. **备菜**：原料实物与标签对应，真实数量，不夸张堆葱姜蒜、花椒辣椒或香菜。
3. **做法**：一张图内4–6个步骤格，动作、火候、时间和完成判断明确。
4. **食用**：与封面同一菜和相同份量，不露脸的家庭吃饭场景。

默认普通家用灶台、锅具瓷盘、自然室内光和手机照片质感，不做电影级棚拍、过分油亮或完美摆盘。文字常用粗白字黑描边，留安全边距。

## 在 ChatGPT 中使用（首选）
给 ChatGPT 上传做饭视频或菜品照片，并在对话内提供本 Skill 的规则，然后直接提出：
- “按四图 Skill 用 GPT 生图，把这个视频生成四张独立3:4图片。”
- “改得更像普通家庭做饭，别用商业美食摄影风格。”
- “羊蝎子只有一斤，葱姜蒜、辣椒、花椒、香菜都少一些，四张图保持同样份量。”
- “只修第二张，保留另外三张。”

**GitHub 仓库链接本身不会自动让所有 ChatGPT 对话加载技能文件。** 需要在对话中提供技能文件内容，或将 `SKILL.md` 及 `references/four-image-spec.md` 加入可供该对话读取的项目资料。ChatGPT 是否能看视频、抽帧、生成/编辑图片，取决于当前可用工具；不能读取素材时不得假称还原原视频。

生图时，每张都要重新明确菜名、主料质量、家庭厨房风格与准确文字；四张须分开生成和验收，不能合成一张四宫格图（第03张内部的步骤格除外）。视频没有提供的用量或时长必须注明为参考建议。

## 其他宿主（非首选）
Codex 如支持技能文件，可安装到技能目录：

```bash
git clone https://github.com/qiushanyueyue/douyin-cooking-four-images.git ~/.codex/skills/douyin-cooking-four-images
```

目录已存在时先比较或备份，不直接覆盖本地修改。其它宿主不一定有 GPT 生图能力，需要确认工具支持。

## 验收及限制
本仓库并不是独立生图程序，不需要额外 API key，但需要宿主具备图像生成、参考图/视频查看能力。生成图不得称为自己实拍，不自动发布，遵循平台 AI 内容标识与素材授权规定。

有实际本地图片时，可运行 `bash scripts/check-four-images.sh /absolute/path/metadata.json`，只检查四个非空文件路径，不验证图像、文字、分量或食谱；如果环境不暴露真实路径，不得假称脚本已通过。
